# Character File — Standard & Template

A character file captures who a character is so the dialogue writer can stay in their voice and
ground every reference in their actual history. One file per character:
`docs/<Character>_Character_File.md`, filled in by the project owner, read by the assistant before
writing any topic node.

A character file is authoring material, not runtime data. Seeds and payoffs are not tracked in the
file — they arise naturally when topic nodes are written against the Memory Index.

Prince and Munir's files are worked examples of this template.

## 1. Identity

Who they are in one breath.

- Full name.
- Age and a one-line profile: how the world sees them.
- Role in the story or community.
- **One-line essence:** the sentence that sums them up.

## 2. Voice

How they speak — pattern-matchable artifacts, not adjectives. The writer must be able to hold a
candidate line against this section and ask "would this character say that?"

- **Verbal tics** — recurring phrases, filler, signature words.
- **Register** — slang, formality, vocabulary.
- **Sentence rhythm** — length, pacing, how they start and end thoughts, what they let go silent.
- **What they'd never say** — the line they won't cross in speech.
- **Example lines** — two or three, ideally lifted from approved dialogue.

## 3. Mannerisms

How they move and what another character would notice.

Rule: if a mannerism can't be noticed and referenced by another character in a spoken line, it
doesn't belong here. Topic nodes have no stage directions — behavior only reaches the player
through dialogue.

## 4. Traits

What they're like, always — the lens over every topic. Dispositions, coping mechanisms, values,
how they love, what drives them. Not events; those go in the Memory Index.

## 5. Relationships

Each relationship in three lines:

- Who they are to the character.
- What the relationship is now.
- **What it colors in talk** — topics it opens, topics it slams shut, the tell when it's touched.

Include relationships that aren't talkable characters — the gang, a lost sibling. These are often
the deepest wells.

## 6. Memory Index

Things that happened. Two tiers:

- **Defining moments** — the events that made them who they are. These earn more prose: the event
  itself, then what it did to them — the belief, fear, or need it left behind. Usually a timeline.
- **Minor memories** — flavor and texture. One or two lines each, concrete enough to reference by
  headline in passing dialogue. These are the seed material for off-hand references.

Rule: if an entry earns more writing, it's a defining moment; if it's a line or two of flavor, it's
a minor memory. A memory may end with an optional line about what it might open.
